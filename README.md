Проект Revit_Sapper состоит из плагина для Autodesk Revit - RevitSapper и оконного приложения WindowSapper. <br>
1. Установите setup.msi.<br>
2. Запустите Autodesk Revit. Согласитесь с загрузкой плагина.<br>
        <img width="1920" height="1016" alt="image" src="https://github.com/user-attachments/assets/1a16d4d8-4dbd-4568-9b80-2d07c0ea6518" />
<br><br>
3. Откройте или создайте новый проект. В панели появится новая вкладка "Сапер".<br>
        <img width="1424" height="121" alt="image" src="https://github.com/user-attachments/assets/fc57907e-2b79-4d3b-ad60-e538bba21a7a" />
<br><br>
4. Нажмите на кнопку "Информация". Ознакомьтесь с информационным окном.<br>
5. Откройте папку по указанному пути. Запустите WindowSapper.exe.<br>
6. В revit появится поле сапера (для лучшей визуализации перейдите в 3D-вид, отображение графики - Тонированный или выше).<br>
        <img width="1920" height="1015" alt="image" src="https://github.com/user-attachments/assets/b20706f3-c028-4ddd-87b1-99b6a20d57dd" />
<br><br>
7. Во время игры в оконном приложении (никак не связанным с revit) поле будет дублироваться на 3D-виде или на виде уровня.<br>
        <img width="1920" height="1017" alt="image" src="https://github.com/user-attachments/assets/a51b1113-a532-40fe-ade0-0e6ff01be67e" />
<br><br>
<h4 align="left"><strong>Этот проект создан для ознакомления с возможностями управления процессом проектирования в revit извне и не претендует на звание лучшего сапера. 
Потому в WindowSapper реализован лишь необходимый функционал для игры.</strong></h4>
